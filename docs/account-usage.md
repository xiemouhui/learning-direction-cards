# API 余额与用量

在「设置与隐私 → 模型与检索设置 → API 余额与用量」查看。打开设置页不自动请求外部账户；只有点击对应刷新按钮才查询，认证信息由服务器发送，不传学习资料。余额和额度仅驻留页面内存，不保存到 SQLite 或个人导出；刷新页面后重新查询。关闭 AI 或搜索不影响手动读取账户信息；演示模式不发请求。

- DeepSeek：`GET https://api.deepseek.com/user/balance`。分别展示币种、可用总额、赠送余额、充值余额、可用状态和查询时间。模型与搜索使用同一 DeepSeek 账户余额。仅支持官方基础地址（含 `/v1`）；自定义兼容代理需在自身控制台查询，不猜测代理余额协议。
- Tavily：`GET https://api.tavily.com/usage`。分别展示当前 Key 的已用/上限、账户套餐已用/上限、按量额度已用/上限。单位为 credits，不转换成货币余额；未提供上限不能解释为无限额度。
- ChatGPT：当前普通模型 Key 未接入余额查询。官方组织 Usage/Costs API 使用单独的管理密钥；本功能不要求增加高权限密钥，提供官方用量控制台入口。没有使用历史未公开的 billing 端点，也没有用模型调用测试余额。

查询失败、未配置、演示模式、不支持和真实零余额分别显示；失败后清除此前页面余额，避免把过期数据当作最新值。不自动重试，不展示供应商原始错误，响应白名单校验并丢弃额外字段，认证请求禁止重定向。

本应用用量直接显示最近七天、当前身份的模型请求数、检索请求数、已知 token 总数，并按 DeepSeek/ChatGPT 展示模型调用与输入/输出 token。实际失败和格式修正重试也计入请求次数；本地模板、缓存命中不计外部调用。用量未知单列，不能按零消费计算。模型搜索所用的账户余额与本地当前身份统计范围不同，不能相减计算余额或推算完整账单。调用元数据沿用三十天保留和删除规则。

协议依据：[DeepSeek 余额接口](https://api-docs.deepseek.com/api/get-user-balance/)、[Tavily 用量接口](https://docs.tavily.com/documentation/api-reference/endpoint/usage)、[ChatGPT 官方 Usage/Costs 示例](https://developers.openai.com/cookbook/examples/completions_usage_api)。

每日上限在设置中配置，默认模型 40 次、检索 20 次，按北京时间及当前身份统计。格式修正重试占用模型次数，剩一次时最多发送一次；请求在服务器事务中预占，失败结束后按实际次数记录。中断未完成的请求保守保留预占至当天结束。达到检索上限时会拒绝本次联网，即使它可能命中缓存；取消联网仍可使用本地建议。其他身份/工具的账户消费不受此处限制，上限不是货币预算。

四平台对照需一次预占四次检索额度、至多一次模型额度，缺少四次时整批拒绝；无资料跳过模型，结束按实际请求次数记录。默认二十次检索额度最多支持五轮完整对照。关闭页面或中断进程不能保证收回已发出请求。
