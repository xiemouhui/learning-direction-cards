# 规则与证据

## 三项独立判断

活动标签正反向同时出现 → 待补信息；只有正向且支持性偏好明确 → 优先尝试；只有正向 → 可以尝试；只有反向 → 当前兴趣较弱；其余未知。自由文字不转换为活动或掌握。当前支持性偏好是各覆盖领域配置的研究/工程两类，尚需真实活动体验的细粒度映射。

准备程度仅看当前入口必要要求：已知低于要求 → 先补基础；有未知或资料缺项 → 验证/补信息；全部入口要求达标 → 可开始当前任务。后续阶段要求单列。时间和资源另列，不影响兴趣。

证据覆盖分别看兴趣、入口知识和时间约束。全自述始终注明实践局限。不存在百分比可信度、综合适配分或职业预测。

## 六类缺口

未知或冲突 → verify；明确不足且必要 → requiredGap；达标且证据满足 → reused；推荐不足 → recommendedGap；拓展 → optional；要求/关系/来源缺失 → unresolved。最低实践证据要求下，自述达标仍先验证。

等级 0–4 是本应用的行为描述，不是高校考试分数或外部认证。修课不自动赋等级，完成任务不自动到 4，失败不自动否定方向。

## 图与规划

六类型节点全局稳定 ID。导航、双向相关、帮助、硬前置、应用、验证分别表达。图校验检查类型、悬空、版本、自环、语义重复、要求硬边与条件选项。一般相关环允许；全部适用候选硬前置环拒绝并定位路径。

不同条件组 AND；同组 OR。已达标高层节点不递归补完所有前置。待补与待验证项展开适用闭包，以 DFS 产生依赖先后。相同条件下稳定 ID 确定顺序。

**当前路线搜索限制**：规划器 1.1.0 最多展开三个完整候选，比较复用、资源和必要缺口，并支持 UI 显式支路选择、保存和重算保留。超出组合上限标 searchLimited；仍不保证全局最优。

ready 指可解释起点，partial 指资料或资源待补，blocked 指无安全路线。缺资料不归为用户不会。每周仅将首项排入至多 min(30 分钟, 用户预算) 的尝试时间盒，非完成时限；其余任务不叠加进本周。0 小时无正时长活动。第 30 天是开始日 +29，第 90 天 +89，两个检查阶段不重叠。

## 确认与历史

每次知识确认追加旧值、新值、依据与时间，更新当前投影并保存完整画像快照。任务回报只存记录。版本冲突拒绝；重复请求使用身份 + 幂等键 + 内容哈希防重。事务回滚覆盖事件和投影。

路线提案记录基础画像/路线版本、差异、预算、过期时间；接受才创建新版本，拒绝不改。活动计划唯一索引约束。历史评估保存当时的可读结果，历史路线按发布版本读知识内容。

## 来源与局限

来源页说明实际支持的主张与取回日。课程与技术文档支持问题、内容与 API 条件；目标行为等级、项目和 rubric 是应用设计映射，未受独立教育评估。checked/verified 不表示学术共识、预测有效性或生产安全认证。

五专业强度为认知描述，课程是概括示例；不作学校统一标准。十二领域均有入门切片，共二十六专题，仍未覆盖完整学科。现代密码学数学准备以特定教材阅读/论证任务为范围，密码工程采用成熟库，不机械复制理论路线。

## 周反馈

上海时区按周一分组，同周最后记录有效。缺周打断连续性。连续两周完成度 ≤2 检查负荷；连续两周难度 ≥4 检查基础与粒度；连续三周兴趣下降且完成度 ≤2 提醒复评。提醒不自动修改路线。

知识撤销追加事件并保存新画像，最新确认可恢复前值，原历史与路线保留。JSON 恢复仅写入空白身份，路线结果与发布版本沿用备份，不自动重新解释。
