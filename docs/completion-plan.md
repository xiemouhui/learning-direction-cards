## 已具备的自检入口

`pnpm services:check` 只读取本地配置，报告 Key 是否存在、接口和模型 ID 格式、是否仍在演示模式，不输出实际密钥、端点或模型值，不访问外部服务。`readyForManualTest` 表示可以开始真实验收，不代表账户成功。

`pnpm knowledge:validate` 检查知识图和覆盖声明。`pnpm test` 检查确定性规则、数据库、适配和配置检查；`pnpm test:e2e` 使用隔离数据库和本地模型 fixture，不使用真实账户。

## 真实验收的授权范围

原始任务书规定新增支出需另有明确授权。真实调用前应明确请求数量、公开测试问题和可能产生费用；不发送个人问卷、经历或数据库。只验证获授权的服务，不因存在 Key 就自动调用。

通过真实账户验收后，记录服务、模型、时间、响应模式、引用和可得用量；不记录 Key。没有提供用量时保持未知，不推算费用。网络错误、无权限、限额或格式错误均应明确失败并保持本地规划可用。
