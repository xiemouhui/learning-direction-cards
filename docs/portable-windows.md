# Windows 免安装测试版

适用 Windows x64；当前版本 0.1.0-preview.3。解压整个 ZIP 后运行，不要在压缩包预览中直接双击。无需另装 Node.js、pnpm 或管理员权限。使用系统默认浏览器，界面地址固定为 http://127.0.0.1:32145，仅监听本机。

## 启动与配置入口

- 双击「启动.vbs」：首次创建空白数据库并同步公共知识库，随后自动打开浏览器；重复启动打开已有实例并签发一次性本机授权。直接输入网址不会新建访问权限；清 Cookie 或授权过期后再次双击启动即可。
- 双击「停止.vbs」：停止免安装版后台服务，保留资料。关闭网页不会停止后台服务。
- 先启动，再双击「配置模型.vbs」：在本机原生窗口输入 Key，默认仅本次运行有效；可选 Windows 账户级加密保存。刷新网页，再明确启用模型或检索。空白提交移除选中凭据。
- 双击「高级设置.vbs」：修改模型 ID、接口信任和本机调用限额等非敏感配置，保存后重启；不要填写原始 Key。
- 双击「打开数据目录.vbs」：查看数据库、配置、启动日志和升级前备份。

如果系统禁用 Windows Script Host，可在程序目录 PowerShell 执行 `& '.\runtime\node.exe' '.\launcher.mjs' start`，停止用 `stop`。所有入口只启动本包附带的 Node，不修改系统 PATH、不安装开机任务。

## 个人资料与升级

资料默认位于 `%LOCALAPPDATA%\LearningDirectionCards`，与解压目录分开。`.env` 仅保存非敏感选项，`security/credentials.dpapi` 保存显式选择记住的加密凭据，`app.db` 保存本机学习资料，`backups` 保留每次启动前的一致性备份；不要公开上传此目录。旧版配置中的 Key 会在启动时加密核验后移除。默认会话凭据不保存；停止后台后失效。完整边界见源码 docs/security.md，无法防御已控制同一 Windows 账户的恶意程序。

升级前在网页导出个人 JSON，停止旧版，解压新版到新目录，再启动。新版先备份已有数据库再迁移，不覆盖已有学习路线；同一用户的数据目录保持不变。不要同时运行不同版本。本包不自动迁移原开发目录的数据；原用户可导出 JSON，在免安装版空白身份预览恢复。

卸载：先停止，再删除解压目录；个人数据仍保留。永久删除个人资料请在网页设置中明确操作；外部备份和配置文件需要本人另行处理。

## 无法启动

服务已就绪但未打开页面时，检查 Windows 默认浏览器的 HTTP 关联，再双击「启动.vbs」；服务无需重启。启动入口等待系统启动结果，失败会显示提示。已有页面接收新的授权片段后自动刷新会话；失败或过期后可重新启动入口。普通网址和页面重试按钮不能签发授权。

首次启动可能需要等待数十秒。服务使用固定本地端口 32145，端口被其他程序占用时会中止，不会终止其他程序。数据目录的 `last-error.txt` 显示简短提示，`service.log` 提供本机诊断。若停用 VBScript，可使用上面的 PowerShell 入口。不要把完整日志或数据目录直接贴到公开 Issue。
