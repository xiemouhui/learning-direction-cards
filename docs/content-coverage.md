## 来源核对与使用边界

新增来源于 2026-10-20 阅读核对，具体 URL、主张与范围保存在发布 JSON，页面“来源与核验范围”可直接查看。包括 Open Robotics ROS 2 Jazzy、MDN、OpenCV 官方仓库、W3C WAI、GOV.UK、MIT OCW、Wireshark、pytest、Pro Git、PostgreSQL、pandas 和 OWASP。

OpenCV 文档站返回访问拦截，改读官方仓库的同一教程正文；不把拦截页计为已核验资料。机器人入口限定软件模拟与通信，不把 ROS 入门等同运动控制能力。SQL 教程本身不要求编程基础，因此不添加无依据的 Python 或命令行硬门槛。可用性专题允许先试运行，但没有参与者的试运行不能标为用户验证。

来源支持具体概念和活动；行为等级、学习次序、验证项目及 rubric 是应用设计，尚未经过独立教育评估。任务完成后仍需要本人明确确认知识变化。AI 与在线检索可解释或补充资料，不自动改写已发布知识图或覆盖标签。
