# 独立用户评估方案（未执行）

三专题的可直接使用任务、参与说明与空白记录表见 [pilot-review.md](pilot-review.md)。包含工作台单步行动、结构化证据、填入自评草稿但不自动提高等级。尚未联系或招募参与者。

建议招募 3–5 名处于不同学习阶段的目标用户。不收集额外真实身份资料，不把开发者的虚构测试当独立反馈。

观察任务：

1. 从目录找到一个具体专题，解释专业、领域、专题的区别。
2. 把一项已知基础、一个未知和一个不足录入画像，解释未知为何不等于不会。
3. 阅读迁移结果，指出复用、验证、必要缺口、来源和主要代价。
4. 完成一次虚构任务回报，确认知识并说明为何还需另行采用新路线。
5. 找到历史，导出并删除虚构资料。

记录：是否能无提示说清下一步、是否把自述当客观证明、是否误读 ready/期限、哪些标签难理解、在哪一步迷路、能否指出来源的局限。记录具体操作与原话前取得参与者同意。

不计算统计准确率、就业成功率或“推荐科学有效”结论。用形成性发现调整信息结构、要求和验证任务，再复测。当前没有任何参与者记录或反馈结论。

新增观察任务：6. 将误填等级撤销，解释旧路线为何不变；7. 导出虚构资料，在空白身份中预览并恢复，解释为何外部开关关闭；8. 指出四个平台的实际匹配数，区分平台搜索入口与已有引用；9. 找到调用上限，并说明次数不等于费用。建议记录是否独立完成、阻塞位置、误解及可观察的下一步，不要求真实经历、真实账户或付费调用。以上任务尚未由独立用户执行。
