后续本地改进：设置可选单个平台，单次仍至多一个搜索请求；来源锚点和缓存指纹随站点变化。无结果时可通过顾问中的外部平台搜索入口自行核对，明确标为导航而非已检索资料。清除实测 Bilibili 跟踪参数，保留公共标题/URL 的离线回放样例。上述改进没有追加真实 API 调用。

已用完本轮三次授权。其他平台的单独查询、更大样本与内容评审仍待后续验收；不自动扩成四次查询或重复整批验收。查询的实际计费以供应商账单为准，不估算费用。
