# 联网探索学习方向

默认范围为 **Bilibili、小红书、百度贴吧、抖音**。用户可在“设置 → 模型与检索设置 → 检索内容范围”切换：

- 学习体验：四个平台的公开视频页面、笔记与帖子，用于观察学习路径、常见困难和个人体验。
- 基础核对：知识库中已核对的官方及参考站点，用于补充理解具体技术概念和要求。

检索服务仍可选 DeepSeek 或 Tavily，与解释模型的服务商独立；本次没有接入四个平台的登录账户或原生私有 API。搜索只能取得服务商可公开索引的内容，不保证四个平台每次都有结果，也不表示已观看完整视频、读取全部评论或取得需登录的笔记。

## 查询与筛选

二十六专题的中英文技术词保存在 `knowledge/retrieval/2026-10-21.3.json`，关联知识发布 `2026-10-21.5`，由 `pnpm knowledge:validate` 一并检查；旧配置原文保留。查询从已发布专题 ID 或准确名称构建，不拼入用户的提问、问卷或证据原文；基础资料不再硬加年份。

例如密码工程的默认公开查询为：

```text
AEAD 认证加密 学习路线 site:bilibili.com OR site:xiaohongshu.com OR site:tieba.baidu.com OR site:douyin.com
```

快速模式每次仍只有一个查询，最多五条展示结果、八秒超时，不因结果不足自动追加付费查询。四平台对照模式则固定四次独立查询，详见 [双模式说明](search-modes.md)。DeepSeek 使用站点条件，Tavily 同时传入限定域名及 restrict 模式，并关闭自动参数升级。

服务端检查 URL 来源、内容页路径、标题或 URL 路径中的技术词；去除跟踪参数和锚点以合并重复项，排除平台搜索页、企业站、假域名和偏题内容。有多个平台的匹配结果时，尽量先展示每个平台一项，再补充其余匹配结果；缺少的平台显示 0，不生成替代来源。

这些是可审查的来源与词语筛选，不等于完整语义检索或事实核验。误杀、漏检和索引覆盖仍需通过更多真实样例改进。

## 来源展示与模型边界

每条社区参考标注平台及“社区经验”。模型实际引用的来源与未被引用的检索参考分别标记；未被回答引用的匹配内容仍可打开，方便自行比较。页面展示公开检索词、返回数、筛除／去重数和平台匹配数量。

个人体验、热度和评论数不作为统一知识前置、掌握标准或就业承诺。网页摘要仍作为不可信上下文传给模型；模型不能修改知识图、个人等级和活动路线。没有匹配资料时明确显示资料不足，继续使用本地依据。

## 缓存与兼容

缓存键包含策略内容、知识版本、检索范围、服务商和接口地址。旧查询和不同范围不混用，读缓存时再次筛选；只有匹配结果缓存七天。偏题与空结果不缓存。旧个人设置没有范围字段时默认四平台；旧客户端省略新字段保存其他设置时，保留已选择范围。

## 验收边界

上次真实搜索的三条偏题结果已固化为精简回放 fixture，并被本次筛选排除。自动测试通过本地 HTTP fixture 验证四平台返回、来源分类、平台数量、无匹配提示及保存范围；它们不是真实平台帖子，也不证明真实 API 的索引覆盖。

本轮没有追加真实付费模型／搜索调用。四平台策略的真实检索质量尚待新的授权验收。
